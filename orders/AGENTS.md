# Вказівки для ШІ-агентів

Якщо завдання стосується папки `samples/`, каталогу шаблонів, нормативних підстав або додавання нового виду наказу, перед змінами повністю прочитайте:

1. `TEMPLATE_LIBRARY.md` — правила аналізу зразків і розвитку бібліотеки.
2. `NORMATIVE.md` — нормативні вимоги та межі автоматичної перевірки.
3. `SECURITY.md` — правила роботи з локальними й персональними даними.

Обов’язкові правила:

- ніколи не додавайте `samples/` або його вміст до Git чи публічного розгортання;
- не переносьте персональні дані й метадані вихідних Word-файлів до шаблонів, тестів або документації;
- не копіюйте нормативну підставу зі зразка без перевірки офіційного джерела;
- спочатку шукайте можливість використати спільний атом або варіант наявного сценарію, а не створюйте дублікат;
- для кожного нового правила лінтера додавайте точний негативний тест і коректний контрольний випадок без спрацювання;
- не називайте чернетку готовим нормативним документом без проходження критеріїв готовності з `TEMPLATE_LIBRARY.md`.
