# ШІ-скарбничка вчителя — редакція 9

## Запуск

Відкрийте `index.html` у браузері або опублікуйте всю папку через GitHub Pages.

## Основні файли

- `index.html` — сторінка практикуму;
- `script.js` — 14 місій, маршрути, прогрес і бібліотека промптів;
- `style.css` — оформлення;
- `materials/` — навчальний текст для місії з файлом.

Прогрес зберігається у браузері. Для перенесення на інший комп’ютер використовуйте експорт та імпорт JSON.
