# ШІ-скарбничка вчителя — редакція 10

## Запуск

Відкрийте `index.html` у браузері або опублікуйте всю папку через GitHub Pages.

## Основні файли

- `index.html` — сторінка практикуму;
- `script.js` — 14 місій, маршрути, прогрес і бібліотека промптів;
- `style.css` — оформлення;
- `materials/` — навчальний текст для місії з файлом.

Прогрес зберігається у браузері. Для перенесення на інший комп’ютер використовуйте експорт та імпорт JSON.

У редакції 10 безпека даних стала першою місією й проходить без звернення до ШІ. Друга місія є першим безпечним запитом, а результати місій 7–14 послідовно збираються в один комплект уроку та повторюваний робочий процес. Прогрес із редакції 9 переноситься автоматично зі збереженням монет і нотаток.
